推送通知

每天定时签到跑完后推送一份汇总。下面三个渠道挑一个填就行，填完勾上「启用推送」再保存。不确定能不能用，就先点那个渠道的「发送测试消息」。

📨 Telegram（推荐，免费、及时）

① 在 Telegram 里搜索 @BotFather → 发 /newbot → 按提示走完，它会给你一串 Bot Token（形如 123456789:AAE...）。
② 把 Token 填到下面，再用你自己的号给这个新 Bot 发一句「hi」（群的话先把 Bot 拉进群）。
③ 点 🔍 自动获取 Chat ID，选一下就行（不点也行，自己填那串数字）。
④ 点 📨 发送测试消息，手机上收到就成功了。

🍎 Bark（iPhone）

在 iPhone 上装 Bark App，把 App 里那串地址的最后一节（Key）复制过来就行。不想用就整块空着。

🔗 通用 Webhook

给一个能收 POST 的网址，面板会发一段 JSON：{"title":"...","body":"..."}。不想用就整块空着。

🔌 浏览器扩展（签到面板助手）

扩展干两件事： ① 一键取 Cookie（连 HttpOnly 都能读，NodeSeek 这类站也行）； ② 当「本地网络中继」 —— 面板点「执行」时请求由扩展在您的浏览器里发出（用您的本机 IP 和登录态）， 所以能绕过 CF 网络的 IP 封禁与人机验证，吾爱破解这类屏蔽机房 IP 的站点也能签。 扩展会自动挂长轮询接单，响应通常在 1 秒内。 用不着在弹窗里点任何「执行」——面板点一下，它自己接单（旧版那个「立即执行待办签到」按钮已删掉）。 扩展需要下面的 API Key 才能连接面板。

中继状态：检测中… 扩展在线时，标记为「🌐 本地网络」的账号会经您的本机网络执行

⬇️ 下载 签到面板助手
安装步骤（4 步，约 1 分钟）
  1. 点上面的「⬇️ 下载 签到面板助手」得到 zip，解压到任意文件夹
  2. 地址栏输入 chrome://extensions/（Edge：edge://extensions/）→ 打开右上角「开发者模式」
  3. 点「加载已解压的扩展程序」，选中解压出的文件夹（不是 zip 本身）
  4. 点扩展图标（工具栏上那个蓝色「签」）→ 把下面这把 API Key 填进去 → 点「🔌 面板连接检查」

这串 Key 只在生成的那一刻显示一次，之后只显示头尾几位（面板不提供「查看」）。 生成后立刻复制到扩展弹窗的「API Key」输入框并保存。忘了或者想换，就点下面的按钮重新生成一把 —— 旧 Key 会立刻失效，扩展要填入新的才能连上。

🌍 社区站点（开源共享）

⭐ GitHub 仓库

面板内置的站点是写死在代码里的；没有内置的网站，谁都可以贡献一份适配： 你用自己的面板把该网站的签到调通（「自定义 HTTP」多步录制，或直接导入别人发的 JSON） → 点「导出为社区配置」拿到一段 JSON → 发到 GitHub 的 Issue / PR 或任意网盘 → 别人粘贴导入就能用。 配置里只会带占位符（{{cookie}} 这种），不会带你的 Cookie，可以放心分享。

📥 导入一份配置

粘贴别人分享的 JSON。也可以只填一条原始链接（GitHub raw / Gist / 自己的网址都行），面板会自己拉取。

📤 导出我的配置

选一个你已经调通签到的网站，导出成可分享的 JSON。 你的 Cookie / 密码会自动换成占位符，不会带出去。

添加账号

取 token 步骤：① 在浏览器登录 akile.ai → ② 点下面按钮复制小书签代码，新建一个书签粘贴进去 → ③ 在 akile.ai 页面点该书签，token 会自动复制 → ④ 粘贴到下方输入框保存。
token 临近过期时面板会自动续期；续期失败会提示重新获取。
快捷录入：在电脑浏览器人工登录该网站并完成一次签到 → F12 网络面板找到签到请求 → 右键「复制为 cURL」→ 粘贴到下面 → 点「从 cURL 导入」（Cookie 会自动带入，无需手动复制）。
也可以输入网站首页地址，点「自动探测」让面板自动寻找候选签到接口，点候选结果即可填入。
